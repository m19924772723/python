# 网络爬虫与采集 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 请求 | requests / httpx | 同步 / 异步 |
| 解析 | BeautifulSoup / lxml | HTML / XML 提取 |
| 动态页 | Playwright | 渲染后抓取 |
| 框架 | Scrapy / Scrapling | 规模化与自适应 |
| 存储 | SQLite / CSV | 落地去重 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **请求与响应**：Header、编码、超时
- **选择器**：CSS / XPath 定位
- **反爬基础**：UA、频率、robots
- **增量策略**：去重与水位线

## 学习路径

1. 先用 requests 抓一个静态页
2. 再学 Playwright 抓动态页
3. 最后做定时增量采集入库
