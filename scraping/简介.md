# 网络爬虫与采集 · 简介

> 用 requests / Playwright / Scrapy 采集网页与接口数据

## 能做什么

- 静态页与动态页抓取
- 接口逆向与批量请求
- 分页遍历与增量更新
- 数据清洗后入库
- 定时采集与监控

## 适合的项目

- **榜单 / 价格监控**：定时取数
- **内容聚合**：多源汇总
- **信息收集**：批量整理

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Python 3.13 venv（requests / lxml / Playwright / Scrapling 已装）、SQLite
- 注意：已装 Playwright 与 Scrapling；注意合规与请求频率

## 快速开始

```bash
python -m venv .venv
pip install requests beautifulsoup4 lxml
python crawl.py
```
