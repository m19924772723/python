# 网络爬虫与采集 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 抓一个页

- **目标**：能取数
- **产出**：一个字段的抓取脚本

- [ ] 请求页面
- [ ] 解析文本
- [ ] 输出结果

## 阶段二 · 批量抓

- **目标**：成规模
- **产出**：整榜 / 整站数据

- [ ] 分页遍历
- [ ] 异常跳过
- [ ] 导出 CSV

## 阶段三 · 入库去重

- **目标**：可持续
- **产出**：增量数据库

- [ ] SQLite 落库
- [ ] 唯一键去重
- [ ] 增量更新

## 阶段四 · 定时采集

- **目标**：自动化
- **产出**：每日自动采集

- [ ] 计划任务
- [ ] 失败重试
- [ ] 变化通知

---

### 里程碑与验收

| 阶段 | 验收标准 |
|---|---|
| 阶段一 · 抓一个页 | 一个字段的抓取脚本 |
| 阶段二 · 批量抓 | 整榜 / 整站数据 |
| 阶段三 · 入库去重 | 增量数据库 |
| 阶段四 · 定时采集 | 每日自动采集 |

> 建议：每完成一个阶段就在本目录下建一个具体项目子目录，把成果固化下来。
