# 网络爬虫与采集 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 抓取

- **列表 + 详情**：两级抓取
- **分页遍历**：自动翻页
- **接口直取**：绕过页面直调 API

## 解析

- **CSS / XPath**：元素定位
- **正则清洗**：提取数字与日期
- **结构化输出**：JSON / CSV

## 稳健

- **重试退避**：失败自愈
- **代理轮换**：降低封禁
- **去重**：按唯一键

## 调度

- **定时任务**：每日执行
- **变更检测**：有更新才通知
- **日志**：过程可回溯

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
