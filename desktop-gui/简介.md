# Python 桌面小工具 · 简介

> 用 Python 做本地桌面小工具（tkinter / PySide / Streamlit）

## 能做什么

- 本地 GUI 工具
- 表单录入与文件选择
- 文件批处理界面
- 本地数据看板
- 打包成 exe 分发

## 适合的项目

- **内部小工具**：同事直接双击用
- **单机数据处理**：不上云
- **本地看板**：可视化本地数据

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Python 3.13（tkinter 内置）、PySide6 / streamlit / flet（需装）、pyinstaller
- 注意：tkinter 零依赖可即时上手；打包 exe 用 pyinstaller

## 快速开始

```bash
pip install flet
python app.py
pyinstaller -F app.py   # 打包 exe
```
