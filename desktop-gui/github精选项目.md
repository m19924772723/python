# Python 桌面小工具 · GitHub 精选项目

> 以下为该方向值得参考的开源项目，星标为 2026-10 前后近似值，请以仓库当前页面为准。
> 「可借鉴」一栏说明读源码或使用时最值得学习的地方。

| 项目 | 星标 | 亮点 | 可借鉴 |
|---|---|---|---|
| [flet-dev/flet](https://github.com/flet-dev/flet) | 14k | Python 跨平台 UI | 用 Python 写多端界面 |
| [streamlit/streamlit](https://github.com/streamlit/streamlit) | 39k | 数据应用框架 | 快速构建交互界面 |
| [pyinstaller/pyinstaller](https://github.com/pyinstaller/pyinstaller) | 13k | 打包 exe | 冻结 Python 应用 |
| [zauberzeug/nicegui](https://github.com/zauberzeug/nicegui) | 12k | 现代 Python Web UI | 自带前端组件 |
| [PySimpleGUI/PySimpleGUI](https://github.com/PySimpleGUI/PySimpleGUI) | 6k | 简化 GUI | 极简 API |

## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
