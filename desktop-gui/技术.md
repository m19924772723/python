# Python 桌面小工具 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 内置 GUI | tkinter | 零依赖、够用 |
| 现代 GUI | PySide6 / PyQt | 专业外观 |
| Web 式 | Streamlit / Flet | 用 Python 写界面 |
| 打包 | PyInstaller / Nuitka | 一键出 exe |
| 配置 | JSON / INI | 用户可改 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **事件循环**：界面与逻辑分离
- **布局管理**：自适应窗口尺寸
- **线程**：耗时任务别卡界面
- **打包**：资源路径与体积

## 学习路径

1. 先用 tkinter 做一个表单工具
2. 再抽配置与批处理逻辑
3. 最后打包成 exe 分发
