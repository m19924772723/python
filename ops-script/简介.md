# 运维与命令行脚本 · 简介

> 运维、批处理与命令行脚本工具

## 能做什么

- 文件批处理与重命名
- 日志分析与统计
- 远程执行与部署
- 定时任务封装
- CLI 工具打包分发

## 适合的项目

- **文件整理**：批量重命名 / 归类
- **日志巡检**：错误统计告警
- **自动化运维**：批量执行命令

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Python 3.13（click / typer / rich / loguru 需装）、pywin32、paramiko
- 注意：Windows 下注意路径与编码；长任务建议加日志

## 快速开始

```bash
pip install typer rich loguru
python tool.py --help
python tool.py run --dir ./data
```
