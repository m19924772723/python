# 运维与命令行脚本 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| CLI | typer / click | 参数与子命令 |
| 输出 | rich | 漂亮的终端输出 |
| 日志 | loguru | 开箱即用 |
| 远程 | paramiko | SSH 执行 |
| 调度 | APScheduler | 定时任务 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **参数解析**：位置参数、选项、子命令
- **日志规范**：级别与轮转
- **异常处理**：失败要看得见
- **幂等**：重复执行不出错

## 学习路径

1. 先写一个脚本加参数
2. 再抽成 CLI 工具
3. 最后打包并接入定时任务
