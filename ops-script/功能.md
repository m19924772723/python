# 运维与命令行脚本 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 文件

- **批量重命名**：规则化
- **归类**：按类型 / 日期
- **查找替换**：内容替换

## 系统

- **进程管理**：启动 / 停止 / 守护
- **环境检查**：版本与依赖
- **远程执行**：批量 SSH

## 日志

- **收集分析**：错误统计
- **告警**：异常通知
- **归档**：定期清理

## 调度

- **定时执行**：计划任务
- **失败重试**：可靠
- **留痕**：执行记录

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
