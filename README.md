# Python — 脚本 / 爬虫 / 自动化 / 数据处理

**定位**：自动化脚本、网络爬虫、文档与图像处理、数据处理与出图

**本机状态**：✅ 可直接开发

**工具链**：Python 3.13.14（托管 venv）：requests / lxml / playwright / PyMuPDF / pypdf / pdfplumber / Pillow / python-pptx / markdown / xlsxwriter / cryptography / COS SDK

**建议技术栈**：requests、Playwright、Pillow、openpyxl / xlsxwriter、pandas / numpy（需补装）

**注意**：⚠️ numpy / pandas / matplotlib / scikit-learn 未装，做数据与画图前先 pip 安装
