# 数据分析与可视化 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 读入与清洗

- **多源读取**：CSV / Excel / JSON
- **缺失处理**：填充与剔除
- **类型规整**：日期与数值

## 分析与统计

- **分组聚合**：按维度汇总
- **透视表**：多维交叉
- **同环比**：趋势对比

## 可视化

- **趋势图**：折线 / 面积
- **分布图**：直方 / 箱线
- **占比图**：饼图 / 条形

## 报告

- **一键出报告**：图文 HTML
- **定时生成**：周期报表
- **导出 Excel**：多 Sheet

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
