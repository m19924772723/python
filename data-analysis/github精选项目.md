# 数据分析与可视化 · GitHub 精选项目

> 以下为该方向值得参考的开源项目，星标为 2026-10 前后近似值，请以仓库当前页面为准。
> 「可借鉴」一栏说明读源码或使用时最值得学习的地方。

| 项目 | 星标 | 亮点 | 可借鉴 |
|---|---|---|---|
| [pandas-dev/pandas](https://github.com/pandas-dev/pandas) | 46k | 数据分析核心 | 向量化与 API 设计 |
| [numpy/numpy](https://github.com/numpy/numpy) | 30k | 数值计算基础 | 数组与高性能 |
| [matplotlib/matplotlib](https://github.com/matplotlib/matplotlib) | 21k | 绘图库 | 可定制与出版级 |
| [plotly/plotly.py](https://github.com/plotly/plotly.py) | 17k | 交互式图表 | Web 交互可视化 |
| [streamlit/streamlit](https://github.com/streamlit/streamlit) | 39k | 数据应用框架 | 几行代码出应用 |

## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
