# 数据分析与可视化 · 开发计划

> 原则：**每个阶段都产出可运行、可验证的东西**，先小步跑通再逐步加深。

## 阶段一 · 读数据

- **目标**：能看数
- **产出**：描述统计结果

- [ ] 装数据栈
- [ ] 读 CSV / Excel
- [ ] 基础统计

## 阶段二 · 清洗聚合

- **目标**：数据可用
- **产出**：干净的汇总表

- [ ] 缺失与类型处理
- [ ] 分组聚合
- [ ] 透视表

## 阶段三 · 可视化

- **目标**：能讲清
- **产出**：一组图表

- [ ] 趋势 / 分布 / 占比图
- [ ] 样式美化
- [ ] 导出图片

## 阶段四 · 自动报告

- **目标**：可交付
- **产出**：定期生成的报告

- [ ] 模板化 HTML
- [ ] 定时生成
- [ ] 邮件 / 通知
