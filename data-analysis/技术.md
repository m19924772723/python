# 数据分析与可视化 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 处理 | pandas / numpy | 数据清洗与计算 |
| 绘图 | matplotlib / plotly | 静态 / 交互 |
| 表格 | openpyxl / xlsxwriter | Excel 读写 |
| 交互 | Jupyter / Streamlit | 探索与展示 |
| 报表 | Jinja2 + HTML | 自动出报告 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **数据结构**：Series / DataFrame 与索引
- **清洗**：缺失值、类型、去重
- **聚合**：groupby 与透视表
- **可视化**：选对图型 + 讲清结论

## 学习路径

1. 先读一个 CSV 做描述统计
2. 再学分组聚合与透视
3. 最后做一份自动生成的图文报告
