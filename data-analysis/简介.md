# 数据分析与可视化 · 简介

> 用 pandas / numpy / matplotlib 做数据分析与可视化报告

## 能做什么

- Excel / CSV 读取与清洗
- 统计聚合与透视
- 图表可视化
- 自动化数据报告
- 与工作台日志联动分析

## 适合的项目

- **学习 / 实验数据分析**：成绩、实验曲线
- **业务报表**：定期汇总出图
- **数据看板**：指标趋势

## 本机环境

- 本机状态：✅ 可直接开发（需补装数据栈）
- 工具链：Python 3.13 venv；**numpy / pandas / matplotlib 未装**，需 pip 安装
- 注意：⚠️ 数据科学三件套未安装，动手前先 pip install numpy pandas matplotlib

## 快速开始

```bash
pip install numpy pandas matplotlib openpyxl
python analyze.py
jupyter notebook   # 可选
```
