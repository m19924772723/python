# AI 与数据流水线 · 简介

> 把 AI 模型接入数据流程，做自动化与智能处理

## 能做什么

- 批量调用大模型
- 文本抽取 / 摘要 / 分类
- 向量检索与相似匹配
- 图文自动生成
- Agent 工具链编排

## 适合的项目

- **批量文案生成**：内容生产
- **智能打标分类**：数据治理
- **知识库构建**：文档问答前置

## 本机环境

- 本机状态：✅ 可直接开发（调用 API 级）
- 工具链：Python / Node、OpenAI 兼容 SDK；本机有 hermes 代理、deepseek-harness（:3080）
- 注意：仅做「调用」级；训练 / 微调需云 GPU

## 快速开始

```bash
pip install openai python-dotenv
python pipeline.py
# 配置 OPENAI_BASE_URL 指向本机代理
```
