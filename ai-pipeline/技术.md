# AI 与数据流水线 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 调用 | OpenAI 兼容 SDK | 多供应商统一 |
| 编排 | LangChain / LangGraph | 链路与状态 |
| 向量 | Chroma / sentence-transformers | 检索 |
| 约束 | Pydantic / JSON Schema | 结构化输出 |
| 调度 | APScheduler / 计划任务 | 定时跑 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **提示与输出**：结构化输出约束与重试
- **嵌入与检索**：向量化与相似度
- **成本控制**：缓存、批处理、模型分级
- **可靠性**：超时、限流、失败兜底

## 学习路径

1. 先写一个单次调用脚本
2. 再做批量与重试
3. 最后加检索与编排
