# Python Web 后端 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 框架 | FastAPI | 类型驱动 + 自动文档 |
| 服务器 | uvicorn | ASGI 高性能 |
| ORM | SQLAlchemy | 成熟通用 |
| 校验 | Pydantic | 类型校验与序列化 |
| 迁移 | Alembic | 数据库版本管理 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **路由与依赖注入**：路径参数、依赖复用
- **Pydantic 模型**：请求 / 响应校验
- **数据库会话**：连接与事务
- **文档**：OpenAPI 自动生成

## 学习路径

1. 先写一个 Hello API
2. 再加数据库与模型
3. 最后加鉴权与部署
