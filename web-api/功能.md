# Python Web 后端 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 接口

- **CRUD**：增删改查
- **分页筛选**：列表通用
- **文件上传**：表单与流式

## 数据

- **ORM 模型**：表映射
- **迁移**：结构演进
- **事务**：一致性

## 安全

- **鉴权**：JWT / OAuth2
- **权限**：接口级控制
- **CORS**：跨域配置

## 部署

- **自动文档**：/docs
- **健康检查**：探活
- **容器化**：Docker 打包

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
