# Python Web 后端 · 简介

> 用 FastAPI / Flask / Django 暴露后端接口

## 能做什么

- REST 接口与自动文档
- 数据库 ORM 与迁移
- 鉴权与权限
- 文件上传下载
- 定时任务与后台作业

## 适合的项目

- **数据接口服务**：给前端 / 脚本调用
- **AI 服务封装**：把模型能力包成 API
- **内部工具后端**：轻量业务

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Python 3.13 venv、FastAPI / Flask（需 pip 装）、SQLite / MySQL（已运行）
- 注意：本机 MySQL 8 与 Redis 已在运行，可直接对接

## 快速开始

```bash
pip install fastapi uvicorn
uvicorn main:app --reload
# 打开 http://127.0.0.1:8000/docs
```
