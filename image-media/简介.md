# 图像与媒体处理 · 简介

> 用 Pillow / OpenCV 做图像与媒体批处理

## 能做什么

- 批量压缩 / 裁剪 / 旋转
- 加水印与格式转换
- 生成缩略图
- 自动抠图
- 视频抽帧与合成

## 适合的项目

- **素材批处理**：配图压缩
- **图片压缩**：减小体积
- **图像预处理**：给模型喂数据

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：Pillow、PyMuPDF、numpy（需装）；ffmpeg 9.0.1 已就绪
- 注意：批量处理前建议输出到新目录，保留原图

## 快速开始

```bash
pip install pillow opencv-python
python batch_img.py ./in ./out
# 输出压缩 / 水印后的图片
```
