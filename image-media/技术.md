# 图像与媒体处理 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| 图像 | Pillow | 读写与基础处理 |
| 视觉 | OpenCV | 算法与视频 |
| 数值 | numpy | 像素级操作 |
| 抠图 | rembg | 一键去背景 |
| 媒体 | ffmpeg | 视频 / 音频 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **色彩与通道**：RGB / RGBA 与位深
- **缩放与采样**：质量与体积平衡
- **批处理**：遍历、命名、异常跳过
- **格式选择**：JPG / PNG / WebP 取舍

## 学习路径

1. 先做单图压缩与裁剪
2. 再批量化并加水印
3. 最后接入视频抽帧
