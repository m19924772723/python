# 图像与媒体处理 · 可实现的典型功能

> 以下为该子方向可落地的功能清单，可作为选题与需求池。

## 图像

- **压缩**：质量与体积可控
- **裁剪 / 缩放**：按尺寸批量
- **格式转换**：JPG / PNG / WebP

## 增强

- **水印**：文字 / 图片
- **锐化增强**：提升观感
- **自动抠图**：去背景

## 视频

- **抽帧**：导出关键帧
- **合成**：图片转视频
- **转码**：格式与码率

## 批量

- **目录遍历**：递归处理
- **命名规则**：统一输出
- **异常跳过**：坏图不影响整体

---

> 每个功能都可独立成一个小项目，建议按「最小可用 → 好用 → 自动化」的顺序推进。
