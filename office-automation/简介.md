# 办公自动化 · 简介

> 用 Python 批量处理 Excel / Word / PDF 与邮件

## 能做什么

- Excel 批量读写与报表汇总
- Word 批量生成与替换
- PDF 拆分 / 合并 / 提取
- PPT 批量生成
- 邮件批量发送

## 适合的项目

- **报表自动化**：日报 / 周报自动生成
- **文档批处理**：合同 / 模板批量产出
- **材料整理**：PDF 归类与提取

## 本机环境

- 本机状态：✅ 可直接开发
- 工具链：openpyxl / xlsxwriter / python-docx / PyMuPDF / pdfplumber / python-pptx / Pillow（多已装）
- 注意：本机 Python 办公类库较全；处理前先备份原文件

## 快速开始

```bash
pip install openpyxl python-docx pdfplumber
python office_job.py
# 输出到 out/ 目录
```
