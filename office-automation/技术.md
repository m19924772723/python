# 办公自动化 · 技术选型

## 推荐技术栈

| 用途 | 推荐 | 说明 |
|---|---|---|
| Excel | openpyxl / xlsxwriter | 读写与样式 |
| Word | python-docx | 文档生成 |
| PDF | PyMuPDF / pdfplumber | 解析与提取 |
| PPT | python-pptx | 幻灯片生成 |
| 邮件 | smtplib + email | 自动发送 |

> 说明：上表为本机可落地的主流选型；「是否已安装」以各分类 README 的实测为准。

## 核心知识

- **Excel 对象模型**：工作簿、工作表、单元格
- **文档模板**：占位符替换生成
- **PDF 解析**：文本层 vs 扫描件
- **邮件规范**：SMTP、附件、编码

## 学习路径

1. 先批量读写一个 Excel
2. 再做 Word / PDF 批处理
3. 最后串成一条自动流水线
