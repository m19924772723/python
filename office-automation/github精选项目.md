# 办公自动化 · GitHub 精选项目

> 以下为该方向值得参考的开源项目，星标为 2026-10 前后近似值，请以仓库当前页面为准。
> 「可借鉴」一栏说明读源码或使用时最值得学习的地方。

| 项目 | 星标 | 亮点 | 可借鉴 |
|---|---|---|---|
| [openpyxl/openpyxl](https://github.com/openpyxl/openpyxl) | 8k | Excel 读写库 | 单元格与样式 API |
| [python-openxml/python-docx](https://github.com/python-openxml/python-docx) | 5k | Word 处理 | 文档对象模型 |
| [pymupdf/PyMuPDF](https://github.com/pymupdf/PyMuPDF) | 9k | PDF 解析 | 高性能文本与图像 |
| [jsvine/pdfplumber](https://github.com/jsvine/pdfplumber) | 7k | PDF 表格提取 | 表格与文本抽取 |
| [scanny/python-pptx](https://github.com/scanny/python-pptx) | 3k | PPT 生成 | 幻灯片编程生成 |

## 使用建议

1. **先跑通再读码**：把项目跑起来，用一遍再回头看实现
2. **带着问题读**：聚焦「它怎么解决某个难点」，而不是逐行通读
3. **小步借鉴**：先抄一个模块的思路，再考虑整体架构
4. **注意许可**：商用前确认开源协议（MIT / Apache-2.0 / AGPL 差异很大）
